# Design System — “BİZ NİYƏ VARIQ?”

## Art direction

Keywords: cinematic, philosophical, scientific, cosmic, minimal, calm, premium.

The visual world should feel like a serious illustrated non-fiction book, not a generated slideshow. Images must clarify a thought, scale or emotional tension. Decoration-only visuals should be rejected.

## Color palette

- Deep navy: `#07111E`
- Near black: `#05070B`
- Soft white: `#F3F5F7`
- Warm gray: `#B8BEC8`
- Muted gray-blue: `#6F7D91`
- Restricted accent: `#B9A46A` or similar muted gold, used rarely

## Typography requirements

Fonts must support Azerbaijani Unicode characters: Ə, ə, Ğ, ğ, İ, ı, Ö, ö, Ş, ş, Ü, ü, Ç, ç.

Recommended testing candidates for later phases:

- Body: Noto Serif, Source Serif 4 or Libertinus Serif.
- Headings: Noto Sans Display, Inter, Source Sans 3 or a restrained serif display pairing.
- Captions/diagrams: Noto Sans or Source Sans 3.

Final font selection must be validated by PDF embedding and Azerbaijani glyph QA.

## Page types

- Type A: Normal text page.
- Type B: Large title with short text.
- Type C: Full-page illustration.
- Type D: Quote page.
- Type E: Scientific diagram page.
- Type F: Timeline.
- Type G: Chapter opener.
- Type H: Reflection page.

## Layout rhythm

Avoid dense continuous text. A typical sequence can vary like this:

1. Chapter opener with a sharp question.
2. 1–2 pages of prose.
3. Diagram or visual spread.
4. Short reflective page.
5. Closing transition into next topic.

Each chapter should not use the same mechanical pattern. Some chapters begin with a scene, some with a fact, some with a contradiction, some with a direct question.

## Scientific/religious separation

Use explicit labels where needed:

- `ELMİN DEDİYİ`
- `FƏLSƏFİ SUAL`
- `DİNİ BAXIŞ`
- `HƏLƏ BİLMİRİK`

These labels are not decorative; they prevent category mistakes.

## Illustration rules

- Realistic or semi-realistic cinematic book illustration.
- No cartoon style.
- No cheap stock-photo look.
- No unnecessary recognizable real faces.
- No anthropomorphic depiction of Allah.
- Scientific diagrams must be checked against research notes.

## Diagram candidates

- Universe timeline.
- Cosmic scale ladder.
- Stellar life cycle and heavy element formation.
- Origin-of-life hypothesis map.
- Branching human evolution timeline.
- Brain and consciousness boundary diagram.
- Human lifespan timeline.
- Biological death process diagram.
- Future universe timeline.

## PDF outputs in later phases

- Print PDF: high quality, print-safe margins, bleed if cover/spreads require it.
- Digital PDF: optimized size, readable on tablets and phones, complete metadata.

No PDF is generated in Phase 1.
